# Kite Code Agents Platform v3 — Functional Foundation & Specialist Agents

Objective: Close every runtime, policy, skill-linking, playbook, routine, AutoPilot, and Thread-continuity gap in Kite Code's `Agents` mode so daily developer workflows work reliably end-to-end, then ship `Ship Guard` and `Discovery Architect` specialists on `antigravity`.
Branch: `feat/response-thread`. Do not commit on `main`.
Delivery strategy: Parallel disjoint execution waves (`T1`–`T9`), keeping each work unit cleanly separated from pre-existing parallel ODDs and gating on `audit-references.mjs --check`, `verify:ipc`, `verify:design`, `tsc`, Vitest, and Cargo suites.
Constraints: Does not change protected zones (`src/components/TitleBar.tsx` mode switcher) and adheres to `AGENTS.md` §1–§3 radius/height tokens. Only `Ship Guard` and `Discovery Architect` are provisioned on `antigravity` (no other specialists added).
Test runner: `cargo test --manifest-path src-tauri/Cargo.toml --bin kite-code agents agent_mind agent_playbooks routines local_autopilot dispatch:: dispatch_wire:: chat::`, `cargo test --manifest-path src-tauri/Cargo.toml --bin kite`, `npm run verify:ipc`, `npm run verify:design`, `npx tsc --noEmit`, `npx vitest run src/components/views/agents src/components/views/routines src/components/views/chat src/components/sidebar/AgentRoster.test.tsx`, `node .kite/sanitizer/audit-references.mjs --check`.
