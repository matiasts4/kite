# Lateral Agent Icons & Reactive Activity Indicators

Objective: Replace plain text `"Working"` / `"Running"` labels and static dots in lateral panels (left `Sidebar`, right `RightDock`) and subagent cards with a reactive 4-dot orbital activity indicator, contextual attention/settled status glyphs, and semantic agent/subagent role icons.
Branch: `feat/response-thread`
Delivery strategy: `single-pr`
Test runner: `npx tsc --noEmit && npx vitest run`

## Specs

### S1. Configurable Reactive Activity Indicator & Shared `AgentStatusIndicator`
- Provide a curated set of 8 running-state activity variants (`matrix-grid` default, `signal-bars`, `pulse-aura`, `kite-diamond`, `matrix-3x3`, `wave-dots`, `radar-sweep`, `chevron-flow`) in `src/components/ui/AgentStatusIndicator.tsx` and `src/components/ui/agent-indicators.css` (imported by `src/index.css`), retiring the legacy 4-dot orbital spinner and sparkle star variants.
- Persist the selected running-state style under `kite.agentActivityIndicator` (`src/lib/kitePrefs.ts`, defaulting to `matrix-grid` with safe fallback for legacy/invalid values) and running-state color under `kite.agentActivityIndicatorColor` (`status` default green, `accent` synced live with `var(--accent)`, `cyan`, `violet`, `amber`, `rose`, `neutral`, or custom `#RRGGBB` hex) with live cross-component reactivity via `useAgentActivityIndicatorStyle()` and `useAgentActivityIndicatorColor()`.
- Expose a compact unified card inside Settings → Appearance (`src/components/views/settings/CustomizationsTab.tsx`) containing the 8 compact style chips (`32px` `--vl-control-md`), inline color/theme-accent sync controls + custom hex picker, and a slim single-row live contextual preview (`Subagents` tab chip, active subagent row, and active thread chip).
- Provide a shared `AgentStatusIndicator` state machine for lateral and subagent rows:
  - Active (`running`, `inProgress`, `in_progress`, `pending`, `queued`, `started`): renders the configured running activity glyph and color (`matrix-grid` + `--status-running` by default) instead of text `"Working"` or `"Running"`.
  - Background working (`backgroundWorking`): renders 3 subtle bouncing circular dots (`kite-dot-bounce`).
  - Attention required (`waiting`, `approval`, `input`, `blocked`, `needsApproval`, `needsInput`, `pendingApproval`): renders a tool-contextual SVG glyph (terminal for command tools, document for file edits/reads, search for grep/find, globe for web/browser, question for user input, fallback shield/bell) with an attention dot and discrete circular pulse ring.
  - Settled outcomes: `completed`/`done`/`ok`/`settled` renders `idleFallback` when supplied or a crisp check-circle glyph; `failed`/`error` renders an error glyph; `killed`/`cancelled`/`stopped` renders a stop/blocked glyph.
- Under `@media (prefers-reduced-motion: reduce)`, infinite animations for all 8 running variants, dot-bounce, and attention pulse MUST stop cleanly (`animation: none`).
- Follow `AGENTS.md` radius and sizing tokens (`--pill-radius`, `--control-radius`, `--card-radius`, `--vl-radius-sm`, `--vl-control-md` 32px, `--vl-control-sm` 26px/28px; no arbitrary pixel radii or heights on interactive buttons/inputs).
