# Multiplexed Provider Daemons & Centralized MCP Hub (Phase 2 of 3)

Objective: Cut multi-conversation + subagent active memory scaling from 4–5 GB down to ~1.0–1.6 GB by replacing 1-process-per-thread/subagent spawns and multiplicative stdio MCP child fan-out with per-provider shared multiplexed daemons (`agy acp --stdio`, shared `opencode serve`, `grok agent stdio`), a centralized HTTP/SSE MCP Hub inside `kite-core`, a global heavy-process concurrency governor, immediate ephemeral subagent reaping, and full CLI resume parity — 100% compatible with official provider subscriptions.
Branch: `feat/remote-control`. Delivery strategy: `work-unit-commits` (forecast ~1,500–2,000 authored changed lines across 6 parallel disjoint units `T1`–`T6` + parent seam wiring).
Test runner: `cargo test --manifest-path src-tauri/Cargo.toml --bin kite-code chat:: dispatch:: core_daemon::`, `npx tsc --noEmit`, `npx vitest run`, `npm run verify:ipc`, `npm run verify:design`, `node .kite/sanitizer/audit-references.mjs --check`.
Series: ODD 2 of 3 for Alternative 3 (follows `odd/tasks/baseline-ram-and-leak-elimination.md`; precedes `odd/tasks/native-rust-agent-fast-lane.md`).
Protected zones: Do NOT modify `src/components/TitleBar.tsx`. Keep all provider drivers strictly bound to observed CLI flags and protocols.
