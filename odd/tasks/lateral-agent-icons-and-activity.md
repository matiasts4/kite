# Lateral Agent Icons & Reactive Activity Indicators

Objective: Replace plain text `"Working"` / `"Running"` labels and static dots in lateral panels (left `Sidebar`, right `RightDock`) and subagent cards with a reactive 4-dot orbital activity indicator, contextual attention/settled status glyphs, and semantic agent/subagent role icons.
Branch: `feat/response-thread`
Delivery strategy: `single-pr`
Test runner: `npx tsc --noEmit && npx vitest run`

## Specs

### S1. Reactive 4-Dot Orbital Spinner & Shared `AgentStatusIndicator`
- Provide a reusable `OrbitDotsSpinner` SVG component (`src/components/ui/AgentStatusIndicator.tsx`) depicting **four circular dots arranged around a ring orbiting continuously in a circle**, styled cleanly in `src/components/ui/agent-indicators.css` (imported by `src/index.css`).
- Provide a shared `AgentStatusIndicator` state machine for lateral and subagent rows:
  - Active (`running`, `inProgress`, `in_progress`, `pending`, `queued`, `started`): renders `<OrbitDotsSpinner />` instead of text `"Working"` or `"Running"`.
  - Background working (`backgroundWorking`): renders 3 subtle bouncing circular dots (`kite-dot-bounce`).
  - Attention required (`waiting`, `approval`, `input`, `blocked`, `needsApproval`, `needsInput`, `pendingApproval`): renders a tool-contextual SVG glyph (terminal for command tools, document for file edits/reads, search for grep/find, globe for web/browser, question for user input, fallback shield/bell) with an attention dot and discrete circular pulse ring.
  - Settled outcomes: `completed`/`done`/`ok`/`settled` renders `idleFallback` when supplied or a crisp check-circle glyph; `failed`/`error` renders an error glyph; `killed`/`cancelled`/`stopped` renders a stop/blocked glyph.
- Under `@media (prefers-reduced-motion: reduce)`, infinite orbital rotation, dot-bounce, and attention pulse animations MUST stop cleanly (`animation: none`).
- Follow `AGENTS.md` radius and sizing tokens (`--pill-radius` for circular dots/rings; no arbitrary pixel heights on interactive buttons/inputs).
