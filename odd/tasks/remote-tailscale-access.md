# Tailscale Remote Access (`Serve`, `Funnel` & `VPN`) + Zero-Re-Pair Auto-Sync

Objective: Enable permanent external-network access from `kite-mobile` to Kite Code Desktop without buying a custom domain or re-scanning pairing QR codes, by integrating Tailscale (`off` VPN-only / `serve` private HTTPS / `funnel` public fixed HTTPS `*.ts.net`) plus optional fixed `publicUrl`, auto-syncing endpoints via `system.bootstrap` and `gateway.endpoints_changed`, and fixing HTTPS default port (`443`) handling on mobile (`v0.2.4`, `versionCode 6`).
Branch: `feat/remote-control` (Desktop) / `main` (`kite-mobile`). Test runner: `cargo test --manifest-path src-tauri/Cargo.toml remote::`, `npm run verify:ipc`, `node scripts/quality/verify-design.mjs --files src/components/views/settings/RemoteTab.tsx src/components/views/settings/remote-tab.css src/lib/ipc/remote.ts`, `npx tsc --noEmit`, `npx vitest run src/lib/remote src/components/views/settings/RemoteTab.test.tsx src/components/views/settings/SettingsModal.test.tsx`, `node .kite/sanitizer/audit-references.mjs --check`, and `kite-mobile` `npx tsc --noEmit` + `npx vitest run`.
Does not change protected zones (`src/components/TitleBar.tsx` mode switcher).

Parse `tailscale status --json` (`BackendState`, `Self.DNSName`, `100.64.0.0/10` IPv4, `MagicDNSSuffix`, Funnel capability) and `tailscale serve status --json` (`Web`, `AllowFunnel` for `127.0.0.1:<port>` / `localhost:<port>`). Switch per-HTTPS-port mode (`off`, `serve` -> `tailscale serve --bg --https=443 http://127.0.0.1:<port>`, `funnel` -> `tailscale funnel --bg --https=443 http://127.0.0.1:<port>`) without calling global `serve reset`, and extract `https://login.tailscale.com/...` approval URLs on activation errors. Validate `publicUrl` strictly (`http://` or `https://`, non-empty host, no whitespace/userinfo/query/fragment/non-root path).
  - Checks: `cargo test --manifest-path src-tauri/Cargo.toml remote::tests::` covering `tailscale status --json`, `tailscale serve status --json` (`off`/`serve`/`funnel`), approval URL extraction, and `publicUrl` validation.
