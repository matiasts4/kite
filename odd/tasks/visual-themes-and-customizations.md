Forecast exceeds 400 authored lines (~1,400 authored lines across schema/persistence, stage backdrops & SVG figures, CSS glass/contrast architecture, terminal/diff sync, and Customizations UI); hold git commits until chain/commit preference on `feat/response-thread` is confirmed.

## Specs

### S1. Visual Theme Packs, `Light | Dark | System` mode, independent per-mode memory, and zero-FOUC boot preseed
User words (sanitized): "Quiero que trabajemos en una parte bastante importante del diseño. Y bueno, tiene que ver con más que nada con el el cómo se ven las cosas. [...] funcionalidades para tener temas. Pero que son visualmente mucho más que cambiar el color de algo, sino que se implementan figuras, imágenes y todo ese tipo de cosas. Es por ende que yo también quiero implementar algo muy similar, que se cambie o afecte a bastante de la interfaz y todo el tema. Debe ser configurable desde la parte de customizations." -> confirmed: "si me parece correcto, quiero que implementes en su totalidad".
Acceptance:
- Support 3 appearance modes: `'light' | 'dark' | 'system'` (tracking `window.matchMedia('(prefers-color-scheme: dark)')` live when `'system'` is active).
- Independently persist and restore `darkThemeId` and `lightThemeId` so switching between Light, Dark, and System never resets the user's chosen dark or light theme back to hardcoded `'kite-dark'` or `'kite-light'`.
- Expand the theme catalog into rich **Visual Theme Packs** (including existing palettes `kite-dark`, `tokyo-night`, `catppuccin-mocha`, `nord`, `dracula`, `kite-light`, `catppuccin-latte`, `solarized-light`, `github-light` plus new curated visual themes `aurora-studio`, `ember-editorial`, and `warm-atelier`), each defining default stage backdrop preset, default hero figure, default surface translucency, syntax theme mapping, and terminal ANSI/surface colors.
- Preseed the saved theme mode, active palette, and custom CSS variables synchronously in `src/main.tsx` before first React paint so startup has zero flash of unstyled/wrong-theme content.
Checks: Unit and hook tests in `src/lib/themeCustomizations.test.ts` and `src/components/app/useAppTheme.test.tsx` verifying `light`/`dark`/`system` transitions, preserved `darkThemeId`/`lightThemeId` memory, and DOM attribute/CSS variable application.

### S2. Stage Backdrop engine: scenic vector illustrations, atmospheric mesh shaders, custom image upload/URL, film grain, and dim-before-blur readability
Acceptance:
- Render a dedicated `StageBackdrop` layer behind the main workspace stage (`App.tsx`) backed by curated high-resolution photorealistic wallpaper artwork (`public/wallpapers/<preset>.jpg`) for each selectable preset:
  - `'theme-default'` (follows active theme pack's signature backdrop)
  - `'none'` (clean solid canvas)
  - `'aurora-mesh'` (*Aurora Boreal* — Nordic midnight aurora borealis ribbons over arctic fjord reflections)
  - `'alpine-dusk'` (*Crepúsculo Alpino* — physically coherent winter blue-hour twilight alpine range with unified snow-dusted dark granite lighting, indigo-violet mist, and starlight, no green summer valleys)
  - `'solar-horizon'` (*Horizonte Solar* — glowing golden-terracotta planetary eclipse corona with orbital starlight arcs over dark sweeping basalt dunes; restored to the preferred original asset)
  - `'event-horizon'` (*Horizonte de Eventos* — ultra-crisp astrophysical deep-space supermassive black hole with razor-sharp photon ring, incandescent volumetric accretion disk, gravitational lensing, and deep starfield, zero mountains)
  - `'lunar-eclipse'` (*Claro de Luna* — large telephoto luminous silver-blue full moon through wispy night clouds over an endless calm open ocean horizon with shimmering water reflection, zero mountains)
  - `'astral-nebula'` (*Nebulosa Astral* — deep-space indigo, sapphire, and emerald cosmic dust clouds illuminated by distant star clusters)
  - `'tokyo-rain'` (*Tokio Sakura* — serene atmospheric night view of illuminated blooming sakura cherry blossoms beside a calm reflective Tokyo canal under deep twilight sky)
  - `'misty-forest'` (*Bosque de Niebla* — photorealistic misty evergreen cedar forest at cool emerald-blue dawn)
  - `'cloud-sea'` (*Pradera Celeste* — lush sunlit rolling green meadow hills beneath an expansive azure blue sky filled with sculpted luminous white clouds, tailored for light themes)
  - `'custom-image'` (user-configured image URL or uploaded local image data URI)
- Deprecated flat-shader presets (`'cyber-prism'`, `'architect-grid'`, `'editorial-paper'`) are migrated smoothly to `'aurora-mesh'` / `'alpine-dusk'` / `'none'` on load.
- Do NOT draw distracting SVG overlays on top of real `.jpg` wallpapers and do NOT run continuous 60fps background animations behind blurred frosted-glass panels (prevents GPU re-blur stalls during scrolling).
- Enforce a **Dim-Before-Blur** readability contract via configurable **Backdrop Dimming** (`0–100%`, default `14%`) and **Backdrop Blur** (`0–32px`) plus an optional **Film Grain / Dither** texture overlay (`grain: boolean`), ensuring foreground text and controls stay legible across all backdrops without washing out the wallpaper.
- Strictly honor `prefers-reduced-motion: reduce` and `html[data-motion='reduce']` by pausing ambient backdrop animations.
Checks: Component tests in `src/components/theme/ThemeVisuals.test.tsx` covering every preset (including wallpaper asset rendering), custom image rendering, dimming/blur/grain CSS variable wiring, and reduced-motion behavior.

### S4. Translucent Frosted Glass surfaces and Contrast architecture
Acceptance:
- Support a **Translucent Surfaces (Frosted Glass)** toggle (`translucent: boolean`, default `true` so any active backdrop shines through panels out of the box), **Surface Opacity** slider (`15–95%`, default `56%`), **Surface Blur** slider (`0–32px`, default `20px`), and **Contrast** slider (`0–100`, default `50`).
- Standardize translucency through a **4-Tier Semantic Glass Token System** in `src/visual-language.css` (solid theme tokens at baseline, dynamically switching to frosted `color-mix` / translucent values under `html[data-surface-glass='true']`) plus reusable utility primitives (`.glass-island`, `.glass-nested`, `.glass-elevated`, `.glass-sticky`, `.glass-overlay`) and reconciled semantic aliases (`--surface`, `--surface-raised`, `--surface-elevated`, `--popover`, `--vl-surface-*`):
  - **Tier 1 (Top-Level Glass Islands)**: `--glass-island-bg`, `--glass-sidebar-bg`, `--glass-blur`, `--glass-border`, `--glass-shadow` applied to `.sidebar`, `.pane`, `.right-dock`, `.code-pane-panel`, `.app-browser-sidebar` (including `--fullscreen`), and floating `.glass-island` surfaces over StageBackdrop.
  - **Tier 2 (Nested Structural Containers & Sticky Headers)**: `--glass-nested-bg` (`transparent` under glass) + `--glass-sticky-bg` / `--glass-sticky-pane-bg` applied across all view wrappers, toolbars, breadcrumbs, gutters, sticky headers (`.workspace-roster__pinned`, `.diff-file-card-header`), `@pierre/diffs` Shadow DOM (`diffRendering.ts`), `Files` (`files.css`, `FilesToolbar.tsx`, `MarkdownPreviewPane.tsx`), `Settings` (`settings.css`, `quotas-tab.css`), `Diffs`, `Browser`, `Workspaces`, `Agents`, `Subagents`, `Notifications`, `Routines`, and `chunks.css`/`bundle.css` views with `backdrop-filter: none` when nested inside a blurred island.
- Tier 3 (Elevated Interactive Surfaces, Composers, Code & Terminal Views inside Scrollable Islands): `--glass-elevated-bg`, `--glass-code-bg`, and `--glass-terminal-bg` applied to cards, composers (`.composer`, `.chat-composer`, `.kite-composer-main`, `.ticket-composer`), inline alerts/banners, `.update-detail-card`, inputs/fields, and terminal canvases (`terminal.css`, `agent-terminal__live`) without stacking redundant `backdrop-filter` inside scrollable containers. Recessed lower context strips (`.kite-composer-context-strip`) attach flush beneath `.kite-composer-main` (`margin-top: 0`, semantic `var(--card-radius)`) without negative overlap so translucent composers across Thread, Agent, and Code never expose doubled bottom-edge contrast bands or stray side-border lines behind model and mode controls, and composer/popover tokens resolve onto Kite's dark/light theme variables (`--text-secondary`, `--text-faint`, `--accent`, `--chip-fill`, `--glass-border`, `--separator`).
  - **Tier 4 (Floating Overlays, Popovers & Heavy Modal Dialogs)**: `--glass-overlay-bg` + `--glass-overlay-blur` applied to menus, popovers, and tooltips (`.ui-menu`, `.ui-popover`, `.ui-tooltip`, inline dropdowns), plus a higher-opacity `--glass-modal-bg` (`clamp(84%, calc(var(--theme-surface-opacity, 56%) + 32%), 96%)`) paired with `--glass-modal-scrim` for modal windows floating over active workspace UI (`.settings-modal-window`, `.ui-sheet.usage-dash`, `.command-palette-card`, `.shortcut-modal-card`, `.notif-modal-dialog`, `.ui-sheet`, `AgentPaneResumeModal`, `ResumeHost`, and `RoutinesView` delete confirmation modal) so underlying chat/code text never washes out dialog legibility; nested `backdrop-filter` is suppressed inside blurred ancestors.
  - **System Resource Monitor Opacity (`SystemResourcePopover`)**: Because `.system-resource-popover` suppresses `backdrop-filter: none` for compositor scroll performance, its container surface uses an opaque solid `var(--menu-plate, var(--pane, #141416))` background (never translucent `--glass-modal-bg` or `--glass-overlay-bg`) in both `SystemResourcePopover.tsx` and `src/visual-language.css` so underlying chat/terminal content never bleeds through.
  - **Notifications Popover, Translucent Toasts & Remaining Small Surfaces**:
    - `AppNotificationsPopover` portals directly onto `document.body` with `surfaceMotion('popover')` on the frosted `.notification-center` dialog (removing the nested `.notification-popover-overlay`/`.notification-popover-anchor` compositing barrier and overlapping `::before` arrow diamond, and removing `.notification-center__section` from Tier 3 elevated cards so group labels render cleanly), while adding layered `--block-fill` / `--block-stroke` cards, a tinted header icon badge + unread pill, and status-tinted icon tiles matching `SystemResourcePopover` and `SubscriptionQuotaPopover` across dark and light theme packs.
    - Sileo toast notifications (`src/lib/toast.ts`, `src/lib/toast.css`, `src/App.tsx`) bind dynamically to the active `appearance` (`dark` / `light`), resolve surface fills from `--menu-plate` / `--pane` instead of hardcoded `#161922`, and apply frosted translucency under `html[data-surface-glass='true']`.
    - `MermaidDiagram.tsx`, `PluginsView.tsx`, and `notifications.css` adopt theme-adaptive tokens (`--block-fill`, `--chip-fill`, `--glass-border`, `--accent-tint`, `--accent-on-fill`, live `kite:theme-changed` re-render for Mermaid) and `AGENTS.md` §1–§2 semantic radii/heights.
- When frosted glass is enabled (`data-surface-glass='true'`), terminal containers across Code mode and Agent mode (`.terminal-view-container`, `.terminal-toolbar`, `.terminal-canvas-area`, `.agent-terminal__live`, `.terminal-surface-host`, `.xterm*`) avoid opaque solid fills and use `--glass-terminal-bg` over the parent frosted pane without adding nested `backdrop-filter` stalls.
- **Border Hierarchy, Surface Elevation & Contrast Calibration**:
  - Separate outer glass island/overlay borders (`--glass-border`, neutral hairline with at most a subtle theme whisper instead of a heavy accent-tinted mix), card borders (`--glass-card-border` / `--glass-card-border-hover`), and nested inner/field borders (`--glass-inner-border`), calibrated for both dark and light modes.
  - Ensure elevated card surfaces (`--glass-elevated-bg`) sit visibly above glass islands and modal dialogs (`.settings-modal-window`, `.ui-sheet`, `.legal-notice__panel`, `.qt-modal-container`) instead of fading below parent opacity, add recessed input wells (`--glass-field-bg`), and preserve `--pane` vs `--composer` / `--menu-plate` surface elevation plus solid `--accent-fill` in `src/lib/themeCustomizations.ts`.
- **Translucent TitleBar Mode Switcher Adaptation**:
  - Adapt `.mode-toggle--stadium` (`Agent | Code | Thread`) and its active indicator backdrop (`.mode-toggle__stadium-backdrop`) to theme-aware translucent frosted glass across dark, light, glass-on, and glass-off states (replacing hardcoded opaque `#090a0d` / `#26282d` / `#838891` fills with semantic theme and glass tokens plus `backdrop-filter: none` so it layers cleanly over the pre-blurred `StageBackdrop` without extra GPU compositor layers), while strictly preserving its protected geometry, padding, dimensions, font metrics, and `layoutId="titlebar-mode-toggle-indicator"` motion (`AGENTS.md` §3).
Checks: Style and DOM token tests verifying `--theme-surface-opacity`, `--theme-surface-blur`, `--theme-contrast`, `data-surface-glass`, 4-tier `--glass-*` tokens and utilities, border/card/field contrast tokens, Sidebar/Files/Diffs/Settings/Popovers translucency, terminal translucency styles, and TitleBar stadium switcher geometry invariance + translucent surface rules.
